# HoneyLog — Cybersecurity Learning Journal

Website jurnal belajar cybersecurity dengan tema gelap dan aksen madu.

## Fitur
- Form Basic Info, Mission Detail, dan Learning Journal.
- Upload serta preview screenshot evidence (disimpan sementara di memori halaman).
- Perhitungan Honey Level, jumlah evidence, dan persentase kelengkapan.
- Autosave field form ke `localStorage` browser.
- Cetak / simpan jurnal sebagai PDF melalui dialog browser.
- Responsive untuk desktop dan mobile.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Buka `index.html` di browser, atau gunakan extension Live Server.

## Deploy
Upload `index.html`, `style.css`, dan `script.js` ke repository GitHub. Untuk GitHub Pages pilih **Settings → Pages**, lalu pilih branch `main` dan folder `/ (root)`. Netlify/Vercel juga dapat men-deploy folder statis ini.

## Catatan penyimpanan
Draft form tersimpan lokal di browser perangkat yang digunakan. Screenshot hanya tersedia selama halaman terbuka dan belum disimpan permanen. Unduh PDF sebelum menutup halaman untuk mengarsipkan catatan dan evidence. Jangan unggah screenshot yang memperlihatkan password, token, flag privat, atau data sensitif.
